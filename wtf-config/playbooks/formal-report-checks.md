# 正式報告書機檢清單

> 搭配 `formal-report-writing.md`。交稿前對正文、表格、文字方塊、圖內文字、腳註全跑；「須 0」者有殘留即未完成，「逐處判讀」者列清單人工處理。
> 表格內 pattern 的 `\|` 是 markdown 跳脫，放進程式前改回 `|`，否則會當字面字元比對而靜默失效。

## 2. 交辦敘事與宣告（須 0 或逐處判讀）

| 項目 | pattern | 標準 |
|---|---|---|
| 會議骨架 | `依.{0,20}會議`、`要求`、`決議`、`據此`、`本案以.{0,10}為依據`、`回應.{0,10}所提` | 逐處判讀 |
| 解釋方法 | `而非`、`未入選`、`僅作.{0,10}註記`、`逐案查證`、`一手資料`、`本案以`、`不重新設定`、`入選`、`選案`、`評等` | 須 0 |
| 表格理由欄 | 表內 `會議`、`期初`、`座談` | 須 0 |
| 延後宣告 | `不預設`、`無法推估`、`俟.{0,20}確定後`、`始能推估`、`本章不`、`本節不`、`不在本章範圍`、`留待` | 須 0（表格「待 PO 查」欄、情境表判斷指標除外） |
| 撰稿用語 | `依第[一二三四五六七八九]章`、`依 ?PO`、`本輪`、`審閱` | 逐處判讀 |

## 3. 文風（須 0 或逐處判讀）

| 項目 | pattern | 標準 |
|---|---|---|
| 列舉導語 | `第[一二三]種是`、`其[一二三]，`、`[一二三]是`、`本小節`、`以下說明` | 須 0 |
| 排比 | `不是.{1,30}而是` | 逐處判讀，只減不增 |
| 自創計量 | `[一二三四五六兩雙]\s?(軌\|段式\|型(?!態)\|面向\|核心)` | 逐處判讀 |
| 口語填充 | `說了算\|守住\|把.{1,10}交給\|不必再\|從頭再做\|其實\|當然\|真的\|東西\|搞\|弄\|一下\|而已\|就是\|一整個` | 逐處判讀（「就是」「弄」可能為正當用法） |
| 模板句 | `綜上\|依上述比較\|理由如下\|分述如下\|詳如下表\|可供.{0,4}參照\|據此建議` | 同節 ≤1 |
| 長段 | 正文段 >250 字且含 `其一\|首先\|此外\|再者`；正文段 ≥3 個數字且 >150 字 | 列清單改列點或小表 |
| 長句 | 句長 >60 字 | 列清單拆句 |

## 5. 引用與圖表結構

- 腳註：document 內 footnoteReference id 皆在 footnotes.xml 有定義；「同註 N」「同前註」指向正確內容（新增、刪除腳註後重查）；每章腳註數 ≤15（目標值）。
- 跨頁引用：`詳[圖表] \d+-\d+(-\d+)?(?!「)` 須 0（編號後須接「名稱」）。
- 欄名：表頭含 `依據` 須 0；含 `與` 列清單人工改寫。
- 圖表標題段：sz=24＋粗體＋置中；圖說段 sz=18、≤2 行；資料表內 sz=20；圖內最小 sz≥18。
- 直接格式：pStyle 為正文／小節／節標題且 pPr 含 spacing 或 ind 的段數須 0；表內段落 ind left≠0 須 0。
- 色彩：圖內與表內字色淺於 #404040 須 0（深底白字除外）。
- 分頁：表標題 keepNext、表列 cantSplit；LibreOffice 轉 PDF 以 `pdftotext` 逐頁列出圖表編號，確認標題與圖表同頁；Word 最終分頁交 PO 目視。

## 6. 改動交付驗證（每次寫入 W_ 檔）

1. 寫入前：sha1 與上次回報一致；`lsof` 無程序開啟；無 `~$` 鎖檔。
2. 備份到 archive，檔名含時間與「○○前」。
3. 副本乾跑 → 各 XML 部件可解析；標題段清單前後相同；腳註參照序列不變或依預期改變；表數、註解數符合預期。
4. 段落文字 diff 只含預期改動（列出改動段，逐條對照派工）。
5. 標紅：改動差異中段拆 run 設 FF0000；純刪除另列回報。
6. LibreOffice 渲染目視改動頁；頁數變化要說明原因。
7. 高風險或跨章改動：交不帶本段對話的 fresh subagent 逐條驗收。
