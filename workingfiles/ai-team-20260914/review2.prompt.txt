## 派工與判斷（動手前先過這關）

**派工鐵律（風險／獨立性判斷，工具中立）：**
- **適合派工**：工作可獨立完成、讀取密集、中間過程會產生大量污染主 context 的輸出、可平行處理（如「找找看」式搜尋、大範圍讀取後摘要）→ 派給適合的執行 agent，主對話只收結論＋`檔案:行號`，不下場讀原文。
- **不適合派工**：修改彼此高度耦合、多人/多 agent 同時動同一區域、協調成本高於直接執行的成本 → 主 agent 自行處理較划算。
- 派工必帶三要素：目標與動機、驗收條件、回報格式。各工具依模型調度規則選執行者（Claude 見 `model-dispatch.md`；其他工具依自身轉接層）；本層按風險與獨立性決定是否派工，模型層再考量額度，不降低驗收標準。
- 說「已完成」之前必有證據：tool 成功回傳＋驗收逐條對照。**高風險或跨模型的成果**：fresh-context 或跨工具獨立驗證；**低風險單點修改**：允許主 agent 自行執行命令與 read-back，不強制每次另派 agent；**ai-team 仍一律由非作者輪流驗收**。檔案交付要經 fresh-context read-back；程式交付要跑測試或實跑。

## 工作品質底線

- **做到好＝自行反覆驗證到符合需求為止**，不是「大致完成就交給使用者檢查」。驗證（截圖、測試、視覺比對）是 AI 的責任。
- 驗收不符 → 繼續修，不交半成品。未驗收就交付＝把處理成本轉嫁給使用者。此規則優先於完成速度。
- **引用統計數值／比較／畫圖前**：必標起訖期間與口徑；不得補參數，同期同口徑才能比較，查不到即標未取得並排除。先讀 `playbooks/data-citation.md`。
- **「量不準／做不到」幾乎都是方法問題**：換更可靠的手段（先算繪成圖再量、放大檢視、固定變因、換量測 API）再下結論。窮盡可靠方法仍不行，才回報做不到。
- **交付可看可聽成品**：主動背景預覽；macOS 用 `/usr/bin/open -g`，影音只顯示所在位置、不自動播放，批次開資料夾；命令與例外見 `playbooks/delivery-conventions.md`。
- **可存檔程式／網頁**：預設指向目標資料夾，記住首次選擇以後寫回；不能精確預設就明示路徑，禁以 Documents 等系統資料夾保底。檢核頁覆蓋原檔；細則先讀 `playbooks/delivery-conventions.md`，FSA 實作再讀 `playbooks/pitfalls-frontend.md`。

## 當前產物 wtf-config/playbooks/data-citation.md
# 數據引用規範：區間、口徑、同期比較
> 適用：任何要在交付物、簡報、圖表、報告中引用統計數值的工作（工具中立、專案中立）
> 用法：動筆寫下第一個數字前先過第 1 節五問；做圖表前再過第 3 節。
> 核心：**數字不會自己說明它在講什麼**。沒有區間與口徑的數值，讀者只能猜，而猜錯的責任算在我方頭上。

## 1. 引用前五問（缺一即不可寫進交付物）

1. **統計期間是什麼？** 起訖年月日，加樣本年數／筆數。「平均年雨量」要問是哪幾年的平均。
2. **口徑是什麼？** 誰統計的、統計範圍（全球／全國／單一測站）、有沒有排除異常值、用什麼定義。
3. **標的是單一還是合計？** 一座水庫還是全區加總、一個部門還是全公司。
4. **單位與型別？** 絕對值還是比率、原始值還是指數、名目還是實質。
5. **查得到出處嗎？** 能指到具體頁面／表號／發布日期，不能只寫「官網」。

答不出任一項 → 回第 5 節「不可驗證即不用」。

## 2. 標示區間

- 任何統計值（平均、累計、比率、成長率、極值）引用時必須同時標示**統計起訖期間**與**樣本範圍**。例：「年平均雨量 2,500 mm（1991–2020 年平均，30 年）」。
- **不得自行推定年段或補參數**。原始資料沒寫是哪幾年，就是沒寫；補上一個看似合理的年段（「應該是 1980–2020 吧」）＝杜撰口徑，比不寫更糟——讀者會以為那是查證過的。
- 圖表的基準線、參考線同樣要標區間。一條沒有區間的「平均線」無法判讀，寧可整條移除。
- 引用對方**已經標好基準的數值時，基準要跟著搬**。原文寫「以某期間月平均值為基準」，我方轉述漏掉基準，等於改寫了它的意思。

## 3. 同期比較

- 跨年比較必須**同月同日或同一統計口徑**（同為年度值、同為累計至某月）。年初對年中不是比較，是誤導。
- **時點不一致的數值不得並列成可比較的視覺**——長條圖、折線圖、並排欄位都會讓讀者預設「這幾個可以互相比」。有季節性的指標（水情、用電、營收、氣溫）尤其致命：枯水期對豐水期的差異來自季節，不來自趨勢。
- 真的要並列不同時點 → 兩種做法擇一：(a) 換成時間軸連續的序列，讓季節波動自己顯現；(b) 保留並列但在圖上明標各時點所屬期別，並在文字說明「不可橫向比較」。
- 「較歷史同期減少 N 成」這類句子，必須交代**同期怎麼定義**（哪幾個月）與**歷史平均的基準年區間**。原文沒交代 → 改寫成不預設參數的說法（「較該單位所稱歷史同期偏低」），不要替它補參數。

## 4. 口徑一致

- 同一份文件內，**同一指標只用一種口徑**。不同來源對同一件事給出不同數字（統計年段不同、定義不同）很常見，混用會在文件內部自相矛盾。
- 來源衝突時：擇一為主，並註明另一口徑的數值與差異原因（例：「A 版為 X（1961–1990 年平均），B 版為 Y（1991–2020 年平均），本文採 B 版」）。**不要平均兩者**，那會產生一個誰都沒發布過的數字。
- 選哪一版的判準（依序）：與交付對象同體系的官方版本 > 統計期間較近、樣本較長 > 口徑寫得較完整。
- 換口徑要全文一起換，含衍生數值（倍數、百分比、差額）。只改一處＝製造新的矛盾。

## 5. 不可驗證即不用

- 查不到區間或口徑定義的統計值 → 標為「未取得」並**排除**，不得用近似說法帶過（「大約」「一般認為」「據了解」）。
- 少一個數字不會讓文件失敗；一個站不住的數字被業主或審查者抓到，整份文件的可信度一起賠進去。
- 若該數值非用不可（例如業主指定引用），改為**轉述並標明責任歸屬**：「依 ◯◯ 單位 YYYY-MM-DD 發布資料」，讓讀者知道口徑未經我方確認。

## 6. 自檢清單（交付前逐條打勾）

- [ ] 文件內每個統計值都能指出出處與統計期間。
- [ ] 沒有任何區間是我方推定的。
- [ ] 每張圖表的座標軸、基準線、資料點都標了期別。
- [ ] 並列比較的數值時點一致；不一致的已加註或改繪。
- [ ] 同一指標全文口徑一致；有衝突的已註明取捨。
- [ ] 查不到口徑的數值已移除，不是留著用模糊語氣蓋過。

# Session Start

每次新對話開場，依序執行下列三步，不需逐步確認；全部完成後回報「已載入全域設定」再詢問任務。

> **前置（自動，無需手動）**：本機 `~/.claude/` 已掛 UserPromptSubmit hook（`wtf-sync.sh`／`wtf-sync.ps1`），在本 session 第一個 prompt 即自動「清 lock → `git pull` → `sync_config.py sync`」（5 分冷卻）。

def check_bundle_integrity():
    """機檢：CLAUDE.md import SHA ＝ bundle 目錄名 ＝ manifest digest，且 bundle 內容與當前 SSOT 一致。
    回傳 (ok: bool|None, notes: list)。ok=None＝未部署 import，由 check_claude_dir 判失敗。"""
    import hashlib
    notes = []
    sha = bundle_sha_in_claude_md()
    if sha is None:
        return None, ["  ! [MISSING] session bundle import 未部署"]
    bundle_dir = CLAUDE_DIR / "wtf-session-bundles" / sha
    manifest = bundle_dir / "manifest.json"
    if not manifest.exists():
        return False, [f"  x [BROKEN ] bundle {sha[:12]}… 目錄或 manifest 不存在"]
    digest = hashlib.sha256(manifest.read_bytes()).hexdigest()
    if digest != sha:
        return False, [f"  x [BROKEN ] manifest digest 與目錄名不符（{digest[:12]}…≠{sha[:12]}…）"]
    for name, ssot in (("GLOBAL.md", SSOT_GLOBAL), ("AGENTS.md", SSOT)):
        bfile = bundle_dir / name
        if not bfile.exists() or not ssot.exists():
            return False, [f"  x [BROKEN ] bundle 或 SSOT 缺 {name}"]
        if hashlib.sha256(bfile.read_bytes()).hexdigest() != hashlib.sha256(ssot.read_bytes()).hexdigest():
            return False, [f"  x [STALE  ] bundle 的 {name} 與當前 SSOT 不一致（需重跑 sync）"]
    notes.append(f"  v [OK     ] session bundle import SHA/manifest/SSOT 三者一致（{sha[:12]}…）")
    return True, notes
