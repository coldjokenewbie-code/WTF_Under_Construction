/to-codex 安裝指南

目標：在你的 Claude Code 裡多一個指令 /to-codex，把工作直接交辦給 Codex CLI 執行，用你自己的 ChatGPT 帳號額度，不用另外申請 API key、不會另外計費。

裝好之後怎麼用：在 Claude Code 打 /to-codex 幫我看看這段程式有沒有問題，Claude Code 會把這句話轉發給 Codex 執行，再把結果貼回對話裡。預設只給建議、不動你的檔案（唯讀模式）。

★貼一段話讓 Claude Code 自己裝

把下面整段貼給你的 Claude Code，它會自己檢查安裝、檢查登入、自己建檔案： 
請幫我設定一個新的 Claude Code skill，叫 /to-codex，用途是把工作交辦給 Codex CLI 執行。

1. 檢查 codex CLI 是否已安裝（command -v codex），沒有就告訴我要跑
   npm install -g @openai/codex（或 macOS brew install codex），先別往下做。
2. 檢查 codex 是否已用 ChatGPT 帳號登入：讀 ~/.codex/auth.json，確認
   auth_mode 是 "chatgpt" 且 tokens.access_token 有值。沒有就告訴我要跑
   codex login，瀏覽器選「Sign in with ChatGPT」（不要選 API key），先別往下做。
3. 兩項都確認後，把附件裡 to-codex/SKILL.md 的內容原文存到
   ~/.claude/skills/to-codex/SKILL.md（資料夾不存在就建立）。
4. 完成後跟我回報，並提醒我可以用「/to-codex <任務內容>」測試，
   預設唯讀（read-only）只給建議不改檔案。

這段話要連同 to-codex/SKILL.md 這個檔案一起丟給 Claude Code（例如拖進對話框），它才讀得到內容去建檔。

預設唯讀，這是刻意的：/to-codex 預設只讓 Codex 讀檔案、給建議，不會幫你改檔案。要它直接動手改，交辦的內容裡要明講「直接改」「幫我修好」這類字眼，Claude Code 才會放行寫入權限。

放行寫入前，先講清楚是哪個資料夾：寫入權限的範圍＝執行當下的工作目錄，不要讓它對整片上層資料夾都有寫入權。不用自己開終端機切目錄——直接在交辦內容裡把資料夾講清楚，例如：
/to-codex 在 ~/Documents/A專案 這個資料夾裡，直接把 XX 修好
Claude Code 會自己切換過去再執行 codex。沒講資料夾、Claude Code 也判斷不出來時，它會反問你要在哪個資料夾操作，回答資料夾名稱或路徑即可。改完自己看一下 diff，確認沒有動到不該動的地方。

1安裝 Codex CLI

終端機（Terminal）打： 
codex --version
有版本號跳出來 → 已經裝過，跳到步驟 2。沒反應／command not found → 執行： 
npm install -g @openai/codex
# macOS 也可以用：brew install codex

2登入 Codex（用 ChatGPT 帳號，不是 API key）

codex login
會開瀏覽器，畫面上選 「Sign in with ChatGPT」，用你的 ChatGPT Plus/Pro/Team 帳號登入即可。
畫面若同時列出「API key」選項，不要選那個——選了就會變成另外計費，跟這份指南的設計不同。

3把 skill 檔放進 Claude Code

這個資料夾裡有一個 to-codex 子資料夾，裡面是 SKILL.md。把整個 to-codex 資料夾複製到： 
~/.claude/skills/
複製完，路徑應該長這樣：~/.claude/skills/to-codex/SKILL.md
用終端機複製（在這份說明所在的資料夾打）

把下面指令貼進終端機（假設你人在這個分享資料夾裡）：

mkdir -p ~/.claude/skills
cp -R ./to-codex ~/.claude/skills/

4重啟 Claude Code，測試

關掉再重開 Claude Code（或開一個新對話），讓它抓到新指令。接著打： 
/to-codex 幫我看看目前這個資料夾的結構，有沒有明顯問題
第一次用會先自動檢查步驟 1、2 有沒有做完；沒做完會直接告訴你缺什麼，照提示補上再打一次 /to-codex 即可。
預設唯讀，這是刻意的：/to-codex 預設只讓 Codex 讀檔案、給建議，不會幫你改檔案。要它直接動手改，交辦的內容裡要明講「直接改」「幫我修好」這類字眼，Claude Code 才會放行寫入權限。

放行寫入前，先講清楚是哪個資料夾：寫入權限的範圍＝執行當下的工作目錄，不要讓它對整片上層資料夾都有寫入權。不用自己開終端機切目錄——直接在交辦內容裡把資料夾講清楚，例如：
/to-codex 在 ~/Documents/A專案 這個資料夾裡，直接把 XX 修好
Claude Code 會自己切換過去再執行 codex。沒講資料夾、Claude Code 也判斷不出來時，它會反問你要在哪個資料夾操作，回答資料夾名稱或路徑即可。改完自己看一下 diff，確認沒有動到不該動的地方。

打 /to-codex 卡住沒反應：通常是 Codex 還沒登入完成，或網路斷線；重新打一次 codex login 確認登入狀態。

想確認現在是不是走 ChatGPT 帳號、不是 API key：終端機打 cat ~/.codex/auth.json 看 auth_mode 欄位是不是 chatgpt。

換電腦要重裝嗎：要，「依序設定」1-3 每台電腦各自跑一次；ChatGPT 帳號登入資訊存在該台電腦本機，不會跨機器同步。
