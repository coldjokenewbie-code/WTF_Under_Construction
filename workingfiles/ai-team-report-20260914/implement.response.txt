          <h1 id="slide-1-title">這次改的是 AI 的工作守則</h1>
          <p class="slide-lead">聚焦三件事：把工作交給合適的模型、手冊找不到時有備援查法、開場不帶非必要細則。這是工作規則的改善，不保證模型每次都能完美照做。</p>
        </div>

        <div class="grid-three">
          <article class="card">
            <div class="card-badge">改動一</div>
            <h2>派對工作</h2>
            <p class="card-before"><strong>以前：</strong>派工表型號與做法過時，未按任務風險區分。</p>
            <p class="card-now"><strong>現在：</strong>依任務風險與驗收成本選人，重制度判定與改動由合適角色處理。</p>
            <p class="card-impact"><strong>影響：</strong>每次派工有明確理由，不再所有事都隨意指派。</p>
          </article>
          <article class="card">
            <div class="card-badge">改動二</div>
            <h2>手冊有備援</h2>
            <p class="card-before"><strong>以前：</strong>開場清單若沒列出技能，缺少統一的備援查法。</p>
            <p class="card-now"><strong>現在：</strong>清單漏列時，能依序查專案索引與全域索引，命中才讀手冊全文。</p>
            <p class="card-impact"><strong>影響：</strong>找不到技能時有標準查法，同時保留本機自有技能。</p>
          </article>
          <article class="card">
            <div class="card-badge">改動三</div>
            <h2>開場少帶細則</h2>
            <p class="card-before"><strong>以前：</strong>版控、預覽與統計等作業細則常駐在每一次開場。</p>
            <p class="card-now"><strong>現在：</strong>主檔保留入口與紅線禁令，完整實作指引搬到需要時才讀的文件。</p>
            <p class="card-impact"><strong>影響：</strong>開場負擔減輕，細則依情境在執行當下查閱。</p>
          </article>

  function goToSlide(targetIndex) {
    if (targetIndex < 0 || targetIndex >= totalSlides) return;

    for (var i = 0; i < totalSlides; i++) {
      var slideEl = document.getElementById('slide-' + (i + 1));
      var tabEl = document.getElementById('tab-' + (i + 1));
      if (slideEl) {
        slideEl.hidden = (i !== targetIndex);
      }
      if (tabEl) {
        tabEl.setAttribute('aria-selected', i === targetIndex ? 'true' : 'false');
      }
    }

    currentSlide = targetIndex;

    var pageCountEl = document.getElementById('page-count');
    if (pageCountEl) {
      pageCountEl.textContent = (currentSlide + 1) + ' / ' + totalSlides;
    }

    var prevBtn = document.getElementById('prev');
    var nextBtn = document.getElementById('next');
    if (prevBtn) prevBtn.disabled = (currentSlide === 0);
    if (nextBtn) nextBtn.disabled = (currentSlide === totalSlides - 1);

    var currentSlideEl = document.getElementById('slide-' + (currentSlide + 1));
    if (currentSlideEl) {
      currentSlideEl.focus();
    }
  }

  function setupNavigation() {
    var prevBtn = document.getElementById('prev');
    var nextBtn = document.getElementById('next');

    if (prevBtn) {
      prevBtn.addEventListener('click', function () {
        goToSlide(currentSlide - 1);
      });
    }

    if (nextBtn) {
      nextBtn.addEventListener('click', function () {
        goToSlide(currentSlide + 1);
      });
    }

    var tabs = document.querySelectorAll('.tab-btn');
    for (var i = 0; i < tabs.length; i++) {
      (function (idx) {
        tabs[idx].addEventListener('click', function () {
          goToSlide(idx);
        });
      })(i);
    }

    document.addEventListener('keydown', function (e) {
      if (e.key !== 'ArrowLeft' && e.key !== 'ArrowRight') return;

      var target = e.target;
      var tag = target ? target.tagName.toLowerCase() : '';
      var isInput = ['input', 'select', 'button', 'a', 'details', 'summary'].indexOf(tag) !== -1;
      var isEditable = target && target.isContentEditable;

      if (isInput || isEditable) return;

      if (e.key === 'ArrowLeft') {
        goToSlide(currentSlide - 1);
      } else if (e.key === 'ArrowRight') {
        goToSlide(currentSlide + 1);
      }
    });
  }
